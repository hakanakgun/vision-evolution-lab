    Source-detail stress test · same active model
    
          
    What disappears as the source loses detail?
    
          
    The microscope keeps the selected detector's native preprocessing and model input unchanged. It only reduces the source image detail before inference, then compares each result with the original-source run.
    
        
    
        
    
          
          
        
    
        
    Choose an image in Time Machine first.
    
        
    Original, 640 px, 320 px and 160 px source-detail levels will run sequentially with the same active detector and confidence threshold.
    
      
    
      
    
      
    
        
    Interpretation boundary
    
        
    Source detail changes; model resolution does not
    
        
    Each reduced image preserves aspect ratio and is then handed to the detector's normal preprocessing path. “Matches vs original” means same canonical class with IoU ≥ 0.50 against this sweep's original-source detections. It measures stability relative to that run, not correctness or ground-truth accuracy.
