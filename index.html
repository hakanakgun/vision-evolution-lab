Pairwise matches require the same canonical class label and IoU ≥ 0.35. Tiny YOLOv2 predicts only Pascal VOC 20 classes; legacy VOC synonyms are mapped to equivalent COCO-style names only for comparison. COCO-only classes cannot match Tiny YOLOv2. These counts are comparison evidence, not accuracy or correctness labels.
